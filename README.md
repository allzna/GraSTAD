# GraSTAD

Graph-guided representation learning for time-series anomaly detection.

## Quick start

Use Python 3.11 or 3.10. Install dependencies and run from the repository root:

```bash
python -m pip install -r requirements.txt
python main.py --data_dir "../datasets/TSB-AD-M" --file_list "./File_List/TSB-AD-M-Eva.csv" --output_dir "./results" --use_revin
```
